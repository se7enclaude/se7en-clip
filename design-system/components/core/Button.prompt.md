Pill-shaped action button; use `primary` (red) for the single main action per view (Télécharger, Upscaler).
```jsx
<Button icon="download" size="lg">Télécharger</Button>
<Button variant="secondary" iconRight="arrow-right">Voir plus</Button>
```
- variants: primary, secondary, ghost, outline, light (white on dark imagery)
- sizes: sm 32px, md 40px, lg 52px. Press scales to .97.
